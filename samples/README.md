# Samples

Fictional messages written for testing. They copy the structure of common Indian job and internship scams (and of genuine offers) but are not real messages, and the company names, numbers and addresses in them are made up or used only as examples.

| File | Expected verdict |
|---|---|
| `scam_fee_whatsapp.txt` | High risk: fee demand, free-mail "TCS" recruiter, Telegram, no interview |
| `scam_task_hinglish.txt` | High risk: Hinglish task scam with daily payouts |
| `scam_lookalike_email.txt` | High risk: lookalike domain, deposit, ID and bank details, short link |
| `genuine_internshala.txt` | Low risk |
| `genuine_campus_offer.txt` | Low risk |
